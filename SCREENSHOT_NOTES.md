# Screenshot provenance

Screenshots in `screenshots/` were captured from the original application's bundled React UI. The capture was performed in an isolated local browser preview without working production authentication or API responses. The application was shown with a fake local-only session for protected UI routes. Consequently, counters display zero and some tables may show loading placeholders. These images are **not** evidence of production data or successful end-to-end operations.

`assets/cover.png` is a graphic composition using those actual UI captures. `assets/gateway-logo.png` and `assets/login-illustration.jpg` were extracted from the supplied frontend image assets.

No source code, compiled JavaScript, environment configuration, credentials, or database file is included in this public-showcase package.
